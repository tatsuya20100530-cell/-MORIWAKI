【MORIWAKI 宮之阪｜パーマタイプ診断 Netlify公開用】

このフォルダは、Netlifyへそのままアップロードして公開できる完成版一式です。
ビルド不要のHTML / CSS / JavaScript構成です。

■ 主な内容
- 5問3択のパーマタイプ診断
- A / B / C の自動集計ロジック
- 2-2-1で同点になった場合の判定ロジック実装
- 診断結果ごとに、ショート / ミディアム / ロングを切り替え表示
- 3タイプ × 3レングス × 3パターン = 合計27スタイル表示
- 結果保存（localStorage）
- 結果シェア（Web Share API / クリップボード）
- 相談導線 / 予約導線
- スマホ向けレスポンシブ対応
- Netlify用 netlify.toml 同梱

■ 公開方法
1. Netlifyへログイン
2. このフォルダ一式をドラッグ＆ドロップ、またはZIPをアップロード
3. 公開完了

■ ファイル構成
- index.html
- styles.css
- app.js
- assets/*.webp
- netlify.toml
