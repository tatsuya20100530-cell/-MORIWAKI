# Googleビジネス6店舗 日次更新チェック

このディレクトリは、ビューティサロンモリワキ6店舗のGoogleビジネスプロフィール日次チェックを管理します。

## 対象店舗
- ビューティサロンモリワキ交野店
- ビューティサロンモリワキ宮之阪店
- ビューティサロンモリワキ凪店
- ビューティサロンモリワキ東寝屋川店
- ビューティサロンモリワキ藤が尾店
- ビューティサロンモリワキ河内磐船店

## 運用
1. 前日の `data/YYYY-MM-DD.csv` または `data/latest.csv` を読む
2. 当日のGoogleビジネスプロフィール／Googleマップ由来の公開情報のみ確認する
3. 当日値 − 前日値で口コミ前日比を計算する
4. 変動なしは必ず `+0件` と表示する
5. 当日確定値を `data/YYYY-MM-DD.csv` に保存する
6. `data/latest.csv` を当日値で更新する
7. A4横1ページPDFを生成・画像検品し、ユーザーへ提示する

## 数値ルール
- 増加: `+N件`
- 変動なし: `+0件`
- 減少: `-N件`
- 当日値を取得できない場合: `確認不可`
- 当日値が取得できない場合の口コミ前日比: `当日値取得不可のため算出不可`
- 第三者サイトの数値で補完しない
- 過去値を当日値として流用しない
